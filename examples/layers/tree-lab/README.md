# TreeLayer

One interactive showcase covers all eight species, four seasons, morphology, crops, and wind. It
opens on a close citrus specimen with seasonal fruit. Switch to the six-tree, same-species grove
to see a row planting with repeatable variation in height, crown shape, foliage, and crop size, or
compare four widely spaced species in the mixed forest. Height, crown spread and depth, branch
density, leaf size, crop shape, attached and fallen crop counts, crop size, and breeze update live.
Drag to pan, scroll to zoom, and hover trees to identify them. The forest keeps the species
comparison light while the grove demonstrates within-species variation.

Run `yarn workspace @deck.gl-community/tree-lab-example start` from the repository root.
The website example also provides WebGL2/WebGPU device tabs.
