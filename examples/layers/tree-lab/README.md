# TreeLayer

Inspect one tree at a time. Switch species or season, adjust crown spread, and
toggle the branch shadows. Gaussian leaves stay out of the opaque shadow map, and
the ground shadow pass skips the floating label background. Drag to pan, scroll to
zoom, and hover to identify the specimen.

Run `yarn workspace @deck.gl-community/tree-lab-example start` from the repository root.
The website also provides WebGL2/WebGPU device tabs; wood shadows are available
with WebGL2.
