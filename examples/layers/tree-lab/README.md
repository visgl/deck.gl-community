# TreeLayer

One interactive showcase covers all eight species, four seasons, morphology, seasonal fruit and
blossoms, and wind. It opens on a close citrus specimen; switch to the eight-tree mixed grove to
compare silhouettes and see the same controls applied to a small planting. Height, crown spread
and depth, branch density, leaf size, and breeze update live. Drag to pan, scroll to zoom, and
hover trees to identify them. The grove is a compact visual example, not a large-inventory
performance test.

Run `yarn workspace @deck.gl-community/tree-lab-example start` from the repository root.
The website example also provides WebGL2/WebGPU device tabs.
