title: React Fiber examples
---

The React Fiber examples are preserved as standalone applications under
[`examples/react-fiber`](https://github.com/visgl/deck.gl-community/tree/master/examples/react-fiber).
Each application consumes the local `@deck.gl-community/react-fiber` workspace
package and keeps the framework's native project structure.

- [Vite](https://github.com/visgl/deck.gl-community/tree/master/examples/react-fiber/vite)
- [Next.js](https://github.com/visgl/deck.gl-community/tree/master/examples/react-fiber/nextjs)
- [React Router](https://github.com/visgl/deck.gl-community/tree/master/examples/react-fiber/react-router)
- [TanStack Start](https://github.com/visgl/deck.gl-community/tree/master/examples/react-fiber/tanstack-start)
