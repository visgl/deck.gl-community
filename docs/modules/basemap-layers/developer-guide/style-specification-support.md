# Style Specification Support

`BasemapLayer` implements a subset of the [MapLibre Style Specification][spec]. This page lists
the parts of the specification and what the module currently does with each. Properties that are
not listed are not supported. Follow-up changes update the table as gaps close.

| Status        | Meaning                                                                            |
| ------------- | ---------------------------------------------------------------------------------- |
| Supported     | Implemented as the specification describes, apart from the notes.                  |
| Partial       | Implemented with a documented approximation, or for some of the values.            |
| Not supported | Ignored, so a style that uses it renders without it, unless a note says otherwise. |

## Layer types

See [Layers][layers]. Layers of an unsupported type are skipped.

| Layer type       | Status        | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------- | ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `background`     | Partial       | `background-color` and `background-opacity`. `background-pattern` is not drawn and, as in the specification, disables `background-color`, so a patterned background draws nothing.                                                                                                                                                                                                                                                                                               |
| `fill`           | Partial       | See [Paint properties](#paint-properties).                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `line`           | Partial       | See [Paint properties](#paint-properties) and [Layout properties](#layout-properties).                                                                                                                                                                                                                                                                                                                                                                                           |
| `symbol`         | Partial       | Text and icons at anchor points: one per point, line and polygon. See [Symbols](#symbols).                                                                                                                                                                                                                                                                                                                                                                                       |
| `fill-extrusion` | Partial       | Patterns and translation are not supported. Shaded as in MapLibre, from the style's [`light`][light]. See [Paint properties](#paint-properties).                                                                                                                                                                                                                                                                                                                                 |
| `raster`         | Partial       | Inline `tiles`, or a TileJSON `url`. The style's own source properties take precedence over the TileJSON's, and only the TileJSON's `tiles`, `minzoom`, `maxzoom`, `attribution`, `bounds`, `scheme`, `tileSize` and `encoding` are used. `scheme: "tms"` and `bounds` are not applied. If the TileJSON cannot be fetched, is invalid or lists no tiles, a warning is logged and the source falls back to its own `tiles`; without them, its layers are skipped.                 |
| `circle`         | Partial       | Points and multipoints of vector sources; circles are not drawn at line and polygon vertices. On a globe, a circle near a tile edge can draw twice, once from each overlapping tile. See [Paint properties](#paint-properties) and [Layout properties](#layout-properties).                                                                                                                                                                                                      |
| `heatmap`        | Not supported |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `hillshade`      | Partial       | Over a `raster-dem` source, in style order. All `hillshade-*` paint properties and `resampling`, with every `hillshade-method`; `multidirectional` takes up to four light sources (MapLibre takes any number). Not drawn at `hillshade-exaggeration: 0`, as in MapLibre. MapLibre snaps hillshade tiles to the pixel grid while the map is still, which moves them by up to half a pixel; `BasemapLayer` does not. Also drawn on a globe. WebGL only; WebGPU draws no hillshade. |
| `color-relief`   | Not supported |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

| `geojson`    | Partial       | Cut into vector tiles on the client with `@maplibre/geojson-vt`, with MapLibre GL JS's settings (512 pixel tiles, extent 8192), then drawn as a vector source: every supported layer type, on a map and on a globe. The data is indexed and its tiles are cut in a web worker, as in MapLibre GL JS, so a large source does not hold the main thread; where no worker can start (no `Worker`, a content security policy without `worker-src`, or a bundle that does not emit the worker, such as Vite's dev server when it pre-bundles this package, unless the package is in `optimizeDeps.exclude`), they are cut on the main thread. `data` is a GeoJSON object or a URL; a URL is fetched when the style resolves, relative to the style URL and with the `fetch` and `fetchOptions` of `loadOptions`. ## Expressions and filters

See [Expressions][expressions].

| Feature                         | Status        | Notes                                                                                           |
| ------------------------------- | ------------- | ----------------------------------------------------------------------------------------------- |
| Constant and data-driven values | Supported     | Evaluated with `@maplibre/maplibre-gl-style-spec`, per feature where the property allows it.    |
| Zoom-dependent values           | Partial       | Evaluated at the zoom rounded down to a 0.25 step, not interpolated continuously.               |
| `feature-state`                 | Not supported | Feature state is always empty.                                                                  |
| `filter`                        | Supported     | Evaluated per feature. `["zoom"]` in a filter uses the integer zoom, as the specification says. |
| Legacy `ref` layers             | Supported     | Resolved when the style loads.                                                                  |

## Layer visibility and zoom range

| Feature                        | Status    | Notes                                                                                                            |
| ------------------------------ | --------- | ---------------------------------------------------------------------------------------------------------------- |
| `minzoom` / `maxzoom`          | Supported | Compared with the exact zoom.                                                                                    |
| Overzoom past source `maxzoom` | Supported | The deepest tiles are scaled up; layers keep drawing.                                                            |
| `layout.visibility`            | Supported | A layer with `visibility: "none"` is not drawn. To change it, pass a new style object, as for other style edits. |

## Layout properties

| Property                       | Status                  | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------------------ | ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `line-cap`, `line-join`        | Partial                 | Per feature. deck.gl has no square cap or bevel join: `square` caps are drawn as `butt`, so a zero-length dash draws nothing where MapLibre draws a square, and `bevel` joins are cut flat half the line width from the vertex.                                                                                                                                                                                                                                                                                                                          |
| `line-miter-limit`             | Partial                 | Per feature. A miter beyond the limit is cut flat at the limit rather than bevelled.                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `symbol-*`, `text-*`, `icon-*` | See [Symbols](#symbols) |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `circle-sort-key`              | Partial                 | Orders the circles within a tile. Tiles draw one after another, so circles in different tiles are not ordered by key.                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `line-sort-key`                | Partial                 | Per feature. Orders a style layer's lines within a tile, lowest key first, as MapLibre GL JS does. Tiles draw one after another, so lines in different tiles are not ordered by key. With `line-gap-width`, a tile's lines draw one side of their gap, in key order, before the other side, so where lines cross, the second side of a lower key can cover the first side of a higher one. With a per-feature `line-cap`, `line-join` or `line-miter-limit`, lines are ordered by key among those of the same shape, which draw one shape after another. |
| Other properties               | Not supported           | For example `fill-sort-key`, `line-round-limit`, `text-writing-mode`, `symbol-avoid-edges`, `symbol-z-order`, the `*-translate` and `*-pitch-alignment` properties, `text-rotation-alignment` for point placement and `icon-halo-*`.                                                                                                                                                                                                                                                                                                                     |

## Symbols

| Feature                                                                        | Status        | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------------------------------------------ | ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `symbol-placement: point`                                                      | Partial       | Points are labelled at the point, and each polygon at its pole of inaccessibility, as in MapLibre. Line features are labelled at the middle vertex of their first part. A polygon in two tiles' buffers is labelled by the tile that holds its pole. Polygon label search is bounded per tile; on a tile with unusually heavy polygon geometry, the remaining polygons are not labelled.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `symbol-placement: line` / `line-center`                                       | Partial       | Symbols are placed along line features as in MapLibre: `line` repeats them every `symbol-spacing` pixels, `line-center` places one at the middle of the line by length. With `line`, features with the same text whose ends meet are joined first, and a label within half a `symbol-spacing` of an earlier one with the same text on the tile is dropped. A placement is skipped where the symbol does not fit on the line or, for text, where the line bends more than `text-max-angle` under it. The symbol's length is the longer of its icon and its text, measured in the label font at the `text-size` of zoom 18 (estimated from the character count while the font loads). Text and icons with `*-rotation-alignment: map` (or `auto`) are turned to the line's direction and drawn flat on the map; text is kept upright (`text-keep-upright`), and icons add `icon-rotate`. With `viewport` they stay upright billboards. The text itself is straight: it does not curve with the line. Placement uses the tile's zoom, so symbols do not move while zooming within a tile. Placement work is bounded per tile; on a tile with unusually heavy line geometry, the remaining symbols are not placed. `text-offset` is not turned with the label. Polygon features are not labelled. |
| `text-field`                                                                   | Supported     | Expressions and legacy `{token}` strings. Arabic is shaped (contextual letter forms and lam-alef ligatures) and right-to-left text is reordered by the Unicode Bidirectional Algorithm, as in MapLibre without its RTL text plugin: wrapped labels per line, after breaking, and labels along lines as a whole.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `text-color`, `text-opacity`                                                   | Supported     | Per feature.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `text-size`                                                                    | Supported     | Per feature. A size of 0 hides the label.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `text-offset`, `text-anchor`                                                   | Supported     | Per feature.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `text-font`                                                                    | Supported     | Drawn with the style's `glyphs`, as in MapLibre; one font stack per style layer and zoom step. Without `glyphs`, or with the `fontFamily` prop, mapped to a CSS font family list, weight and style. See [Label fonts](/docs/modules/basemap-layers#label-fonts).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `text-halo-color`, `text-halo-width`                                           | Partial       | Per feature. Drawn around the glyphs, at most a quarter of the text size wide, as in MapLibre. Widths are rounded to 0.25 px. Each distinct halo in a tile is drawn by its own text sublayer, for at most 8 halos per tile and style layer: the most common ones. Labels with any other halo get the most common halo; labels without a halo never get one. The halo's outline width depends on the text size, so each data-driven `text-size` value also needs its own halo; past the cap, a label drawn with another size's halo is off by the ratio of the two text sizes. Where labels with different halos overlap, they stack by sublayer rather than in label order. Translucent text (a `text-color` alpha or `text-opacity` below 1, or a label fading in or out) is drawn twice inside the glyph, so a halo makes it more opaque: an alpha of 0.5 draws as 0.75. MapLibre draws the halo under the glyph instead. All labels, with or without a halo, use a signed distance field font atlas with an 18 px buffer around each 64 px glyph: the atlas holds about half as many glyphs as a plain one within the GPU's texture size limit (about 1,600 distinct ideographs per font at 16,384 px).                                                                                    |
| `text-halo-blur`                                                               | Partial       | Per feature, rounded to 0.25 px. As in MapLibre, the halo edge fades over `1.19 * blur` px on each side. Each distinct blur in a tile needs its own halo, within the same cap of 8. The fade ends where the glyph distance field ends, about 0.28 of the text size past the glyph. WebGL only; WebGPU draws a sharp halo.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `text-max-width`                                                               | Supported     | Per feature, for `symbol-placement: point`. As in MapLibre, the icon turns about its anchor point, with its `icon-anchor` and `icon-offset`. The icon collides with its turned box, where MapLibre uses the axis-aligned box around it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `icon-rotation-alignment`                                                      | Partial       | `map`, or `auto` along lines: the icon is drawn flat on the map and turns with it, and along lines it is turned to the line's direction. `viewport`, or `auto` at points: the icon is a billboard, turned only by `icon-rotate`. `icon-pitch-alignment` is not read: an icon lies flat exactly when it turns with the map. On a globe, icons are always billboards, turned on screen.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `icon-padding`                                                                 | Supported     | Per feature, one to four values. Widens the icon's box on each side, as in MapLibre.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `icon-text-fit`                                                                | Not supported |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |

## Style resources

| Feature                            | Status        | Notes                                                                                                                                                                                                                             |
| ---------------------------------- | ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`sprite`][sprite]                 | Supported     | A single URL or the array form. `@2x` is requested first when the device pixel ratio is above 1, as in MapLibre. URLs may carry query strings.                                                                                    |
| [`glyphs`][glyphs]                 | Supported     | Loaded per font stack and 256-character range as labels need them. CJK ideographs, hangul and kana are drawn with the browser's `sans-serif` font, as with MapLibre's default `localIdeographFontFamily`, at half its resolution. |
| [`light`][light]                   | Supported     | `anchor`, `position`, `color` and `intensity`, with zoom expressions, shade `fill-extrusion` layers as in MapLibre. On a globe, the light keeps its position relative to the ground under each building. WebGL only.              |
| [`sky`][sky], [`terrain`][terrain] | Not supported |                                                                                                                                                                                                                                   |
| [`projection`][projection]         | Not supported | Use deck.gl's `MapView` or `GlobeView`, with the `mode` prop.                                                                                                                                                                     |

## Rendering

| Feature    | Status  | Notes                                                                                                                                                                                                                                                                                                                                                                                                           |
| ---------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Draw order | Partial | Style layers draw in style order across sources and tiles, as in MapLibre: each layer draws in every tile before the next, so a tile's fills do not cover a neighbouring tile's labels. A vector source split by another source's layers draws as one tile layer per run, and the runs share one cache of decoded tiles per source. A flat layer after a `fill-extrusion` layer is hidden behind the buildings. |
| Globe view | Partial | `mode: 'globe'` draws on deck.gl's `GlobeView`, with an optional atmosphere (see the [`globe`](/docs/modules/basemap-layers/api-reference/basemap-layer#globe) prop). Labels and icons whose anchor is beyond the globe's horizon are hidden, on WebGL only; they disappear at once, where MapLibre GL JS fades them out.                                                                                       |
