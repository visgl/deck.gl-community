# TreeLayer

TreeLayer now lives in [`@deck.gl-community/layers`](/docs/modules/layers/api-reference/tree-layer), using native vis.gl geometry. The old package re-exports the same constructor for compatibility.

See the new API reference for seasonal crowns, crop-radius migration, highest-quality geometry, wind and shadows, and [Tree Lab](/examples/layers/tree-lab) for original/native comparisons.
